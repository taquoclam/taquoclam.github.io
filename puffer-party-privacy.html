Privacy Policy — Puffer Party Auto Answer

Effective date: November 7, 2026

Developer contact: taquoclam@gmail.com

Overview

Puffer Party Auto Answer is an unofficial browser extension that provides local answer suggestions, tracks previously attempted answers, and optionally types or submits answers for the Krillion Puffer Party game. The extension is not affiliated with Krillion.

Data the extension handles

The extension reads visible game questions and interacts with the game answer field. It locally stores extension settings, custom answer mappings, previously attempted or skipped answers, and (if provided) an OpenAI API key using Chrome extension storage.

The extension does not ask for a name, postal address, payment card, or a user account of its own. It does not include analytics, advertising trackers, or an independent developer-operated data collection server.

How information is used

Local information is used to provide answer suggestions, maintain settings, and avoid suggesting answers already attempted or skipped for a given question. Most supported categories use an answer list bundled with the extension and do not require an external AI service.

Optional OpenAI API requests

When the user chooses to configure and use the optional AI answer feature, the extension sends the current game question and relevant previously used answer hints to the OpenAI API at api.openai.com. The user-provided API key is transmitted to OpenAI to authenticate the request. OpenAI processes information under its applicable policies and terms. AI-generated answers are suggestions, not guaranteed valid game answers.

Without an API key configured, the extension does not make requests to OpenAI for answer suggestions.

Game website

When the extension enters or submits an answer, that content is provided to the Krillion game webpage. Krillion's own handling of game data is governed by its policies and is outside this extension's control.

Storage and security

Settings, answer history, custom mappings, and an optional API key are held in the browser's local extension storage. The extension does not add its own encryption to the stored API key. Requests to the OpenAI API use HTTPS. Users should avoid sharing browser profiles containing their API credentials.

Data retention and deletion

The extension retains local settings and history until changed or cleared. Users can clear attempted-answer history through the extension, remove the saved API key through its settings, or delete all extension data by removing the extension or clearing its storage. Data already sent to OpenAI or Krillion is subject to those providers' respective retention practices.

Sharing and sale of data

The developer does not sell extension user data. The extension shares the limited data described above with OpenAI only when the optional AI feature is used; game answers are entered into the Krillion website as part of the user's chosen game interaction.

Changes to this policy

This policy may be updated when the extension's features or data handling change. The effective date at the top will be revised for material updates.

Contact

Questions about this policy may be sent to taquoclam@gmail.com.
